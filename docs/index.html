BUILT TO STAY OUT OF THE WAY

Simple controls. Local operation.

Designed as a small utility, not another application you need to manage.

▧

Lives in your tray

Start, stop, see status, and open logs from the Windows notification area. No persistent terminal window.

⊘

Targets ad requests

Uses Chromium DevTools Protocol to attempt to block selected third-party advertising network URLs.

◫

Hides empty ad space

Optional CSS rules attempt to remove some known ad containers and reduce unused right-rail space.

⌘

Reversible by design

No patches to Blitz binaries, Riot Vanguard, League of Legends, DNS settings, or the Windows hosts file.

GETTING STARTED

Ready in a few steps.

The tool uses components already present on Windows 10 and 11.

  1. 01

    Download and extract

    Download the portable Windows application ZIP from GitHub and extract the complete folder. Avoid running files directly from within the archive.

  2. 02

    Fully quit Blitz

    Exit the desktop app and its existing notification-area icon before launching Shield.

  3. 03

    Start the tray launcher

    Double-click Launch-Blitz-Ad-Shield.vbs, or use Run-Blitz-Ad-Shield.cmd if VBScript is disabled.

  4. 04

    Manage from the shield icon

    Find the icon in your Windows tray, then right-click for Start, Stop, Logs, Exit, and Check for updates. Future versions install automatically when you launch Shield with Blitz closed.

IMPORTANT TO KNOW

Read this before using Shield.

Blitz Ad Shield starts Blitz with a localhost Chromium debugging port. This is more powerful than an ordinary ad-blocking browser extension.

Keep it local. Other programs on the same PC may be able to access Blitz's debugging session. Only use it on a trusted machine.

Fully quit Blitz afterward. Exiting Shield by itself does not close Blitz's debugging port.

Blitz changes over time. App updates may affect ad filtering, layout, or the overlay. Report issues on GitHub.
